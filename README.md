# 화장품 산업 트래커

화장품 수출입, 지역 비중, ODM 손익·가동률과 글로벌 컨퍼런스콜을 살펴보는 한국어 대시보드입니다.

- 국가별 수출/수입, 4·8권역, 카테고리, 월·분기, YoY, 주요국, 국가 순위
- 지역별 수출 비중, 중화권 의존도, 월별·3개월 누적
- ODM 3사 연결·화장품 기준 매출, 영업이익, 성장률, 이익률
- 국내 생산능력·실적·가동률, 연간·분기 및 회사별 비교
- 16개사 컨콜 히트맵, 지역·주제·회사 필터, 한국어 요약과 원문 링크
- 모든 차트 숫자표, CSV 다운로드, 범례 숨김, 항목 강조 고정

## 실행 및 배포

Node.js 22.13 이상에서 `npm install`, `npm run dev`로 실행합니다.
`npm run build`는 타입 검사 후 GitHub Pages용 정적 파일을 `docs/`에 생성합니다.
Pages 설정은 `main` 브랜치의 `/docs`입니다. 원본 코드 변경 시 빌드한 `docs/`를 함께 커밋합니다.

## 자료 범위

2026-09-30에 확인한 [참고 대시보드](https://kbeauty-app-hj-aiproject1-handy.vercel.app/)의 공개 자료 스냅샷입니다.
무역은 2014년 1월~2026년 8월, ODM 재무는 2Q26까지입니다. 관세청·DART가 원자료 출처입니다.
현재 자동 수집은 연결되어 있지 않습니다. 원본의 숫자 자료를 사용하고 컨콜은 자체 한국어 사실 요약으로 제공합니다.
2026년 생산능력·실적 연간 수치는 반기 연환산이며, 자세한 집계 기준은 각 탭에 표시합니다.
누락값은 0으로 바꾸지 않으며, 미완료 분기는 분기 집계에서 제외합니다.

디자인은 사용자 소유 [Amazon-Tracker](https://cbturbomax.github.io/Amazon-Tracker/)의 고정 규칙을 따릅니다.
